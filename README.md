# ✈️ Mi Espacio Minimalista — Cuaderno de Viajes & Desarrollo Web

¡Hola! Bienvenido/a al repositorio de mi web personal. Este proyecto combina mi pasión por el diseño limpio y la planificación de viajes con el desarrollo frontend desde cero, sin depender de librerías ni frameworks externos.

## ✨ Sobre el proyecto

La web funciona como un **espacio editorial y cuaderno de bitácora** para organizar futuros destinos, presupuestos e itinerarios (como el próximo viaje a Disneyland París en 2027), aplicando una estética minimalista enfocada en la legibilidad y la experiencia de usuario.

### Funcionalidades destacadas
* **Modo Claro / Oscuro:** Cambio de tema dinámico con guardado automático de preferencias en el navegador mediante `localStorage`.
* **Navegación fluida:** Transición dinámica entre secciones en la página principal sin necesidad de recargar el navegador.
* **Galería Editorial & Lightbox:** Visualización de fotografías en cuadrícula asimétrica con visor a pantalla completa, pies de foto y cierre mediante teclado (`Esc`) o clic externo.
* **Planificador Interactivo:** Desglose de presupuestos, enlaces directos a alojamientos y lista de tareas (*checklist*) interactiva para cada itinerario.
* **Formulario de Contacto Funcional:** Integración asíncrona (`fetch`) con Formspree para recibir mensajes directos con validación y estados de envío.

## 🛠️ Tecnologías utilizadas

* **HTML5:** Maquetación semántica y accesible (`<figure>`, `<figcaption>`, `<nav>`, `<main>`).
* **CSS3:** Variables nativas (`:root`) para gestión de temas, CSS Grid, Flexbox, diseño adaptable (*responsive*) y animaciones suaves.
* **JavaScript (Vanilla):** Manipulación del DOM, gestión de eventos, persistencia de datos locales y peticiones asíncronas.

