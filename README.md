# 🌐 Portfolio de Desarrollo Web — Marina Tejero

¡Hola! Bienvenido/a a mi portfolio personal. Este proyecto reúne mi trabajo, habilidades y evolución como desarrolladora web.

## ✨ Sobre el proyecto
El objetivo de esta web es presentar de forma clara y visual mis proyectos de desarrollo frontend, aplicando buenas prácticas de maquetación, diseño adaptable (*responsive*) e interactividad.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Estructura semántica y accesible.
* **CSS3:** Diseño moderno, estilos personalizados y adaptación a distintos dispositivos.
* **JavaScript:** Interactividad y dinamismo en la interfaz.
